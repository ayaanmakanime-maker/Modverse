# Human Studio assets

`human/` holds the CC0 MakeHuman base mesh, morph targets, rig and the CC0 parts (outfits, trousers, shoes) used by Human Studio — see `docs/HUMAN_STUDIO.md` and `docs/HUMAN_AND_PHYSICS_SOURCES.md` for sources and licences.

The supplied `man.fbx` / `woman.fbx` characters (Atlas / Aura) were retired and removed; fitting now happens on the Human Studio mannequin.
